Ce que je livre en 10 à 14 semaines

Deux ans de Symfony en production : je n'arrive pas pour apprendre le métier. Un stage court peut livrer un sujet délimité, de bout en bout.

  • 01

    Un module métier

    Modèle de données, back-end Symfony, interface, tests, mise en production.

  • 02

    Une API

    Endpoints documentés, validation stricte, 4xx pour les cas prévus, 5xx pour les vrais bugs.

    Une migration

    Montée de version PHP ou Symfony, refonte de schéma MySQL, reprise de données sans coupure.

  • 04

    Une couverture de tests

    PHPStan, PHPUnit et Playwright sur les parcours critiques, branchés dans la CI.
