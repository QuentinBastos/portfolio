Team project (4), CPE Lyon · 2026

IoT micro:bit

End-to-end IoT architecture: sensors, encrypted radio, server and Android app.

Code on GitHub

A micro:bit reads temperature, humidity, pressure and light and sends them over radio to a gateway, which relays them to a Python server. An Android app shows the readings and remotely sets what an OLED screen displays.

My role. Android app, protocol with the server and security.

What I did

  • Android app in Java with Material 3: receiving readings and sending commands.
  • Protocol between the app and the server, over UDP on Wi-Fi.
  • AES-128 encryption of the radio link between device and gateway.
