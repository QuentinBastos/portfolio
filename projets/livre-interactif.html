Projet d'équipe (2), IUT · 2024

Livre interactif

Création et partage de livres interactifs, avec génération d’histoires par IA.

Code sur GitHub

Écrire des récits, y ajouter textes, images et liens, puis les partager. Une fonction de génération s'appuie sur l'API OpenAI pour écrire une histoire à partir de quelques mots.

Mon rôle. Développeur back-end, en binôme.

Ce que j'ai fait

  • Back-end Symfony : modélisation des livres, de leurs pages et de leurs liens.
  • Intégration de l'API OpenAI pour générer des histoires à partir d'une consigne courte.
  • Conteneurisation de l'application avec Docker.

Stack

  • Symfony
  • Twig
  • Tailwind
  • Sass
  • OpenAI API
  • Docker
