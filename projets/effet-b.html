Effet B développe des applications métier sur mesure, la plupart sur un CMS interne partagé par plus de 20 projets. J'y travaille depuis 2024, en alternance depuis 2025, sur des ERP en Symfony et sur des projets PHP repris d'autres équipes.

ERP e-commerce : refonte des documents commerciaux

ERP e-commerce de pièces détachées, sur Symfony et le CMS interne. Les devis, commandes, bons de livraison et factures étaient peu reliés entre eux. J'ai restructuré la base pour que chaque ligne d'un devis se retrouve dans la commande, puis la livraison, puis la facture, avec une traçabilité complète.

Le plus délicat : migrer tous les documents existants sans casser la facturation en production. Migration progressive, scripts dédiés, tests sur des copies de données réelles.

Aussi livré : fiche client créée automatiquement depuis une demande de devis, bons de commande fournisseurs, saisie d'adresse assistée, tableau de bord statistiques, retours d'inventaire.

ERP automobile : coffre-fort numérique par API

Un ERP qui digitalise les concessions automobiles, notamment les dossiers d'immatriculation. Ma mission : y brancher un coffre-fort numérique certifié, fourni par un prestataire externe, pour que chaque concession archive ses documents de façon conforme.

J'ai écrit le client API (authentification, envoi des documents), le provisionnement automatique d'un coffre par concession, les dépôts manuels et automatiques, et la réception des webhooks qui synchronisent l'état des dépôts. Côté sécurité : validation des clés AES-256, assainissement des données, gestion des cas limites.

ERP de maintenance : reprise de code legacy

ERP de maintenance repris par l'agence, sans documentation. J'ai refondu tout le module client : fiche en quatre onglets, tables d'administration, matrices tarifaires par type de contrat avec import et export Excel, archivage des clients avec historique. Mon plus gros volume de code de l'année, fait en binôme avec un développeur senior.

Ce que ça apporte à une équipe

Lire et reprendre du code que je n'ai pas écrit, livrer sur des bases de production qui facturent de vrais clients, intégrer une API tierce proprement, et corriger les bugs remontés par Sentry. C'est le quotidien d'une équipe produit, et c'est ce que je fais depuis deux ans.
